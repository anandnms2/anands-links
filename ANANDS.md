# Anands Links
Linkwarden fork: Anands orange/black/grey theme (daisyUI tokens in apps/web/tailwind.config.js), logo set in apps/web/public, Authentik SSO enabled via env.
Deploy: `cp .env.anands.example .env`, fill secrets, `docker compose up -d`. Image is built by .github/workflows/build-image.yml to ghcr.io/anandnms2/anands-links.
